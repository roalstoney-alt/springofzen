# Ocean Room 001 — Base Art v0.3

Status: implemented for web; physical projector calibration remains pending.

## Direction

The room is photographed from approximately 100 cm above the floor. It is intimate, reachable, and deliberately under-styled. The base art contains no digital organisms or ocean effects.

## Desktop master

`assets/ocean-room-base-v03-desktop.jpg` is a dedicated 16:9 composition. The floor occupies roughly the lower third rather than half the frame. A very low rounded oak bed, simple cream bedding, one muted blue-grey textile, and a large whale room friend create an everyday sleeping place. Milo rests naturally toward the outer/head corner instead of being centered on pillows.

The bedside object is a smooth matte pearl light without shell grooves. The shelf object is a rounded sandstone form without holes or coral geometry. The low shelf holds a few books and one box, leaving visible empty space.

## Mobile master

`assets/ocean-room-base-v03-mobile.jpg` is independently generated at 9:16. It simultaneously preserves Milo, part of the low bed, the shelf, Reef Accent, Shell Light, and a large reachable floor area. It is not derived by cropping desktop coordinates.

## Exclusions

No people, wall art, plants, boats, toy houses, teddy bears, aquarium decoration, literal shells, coral, ocean wallpaper, projection, digital creatures, text, UI, or styled throw blankets appear in either master.

## Acceptance

Both masters must read as rooms a parent could build and live with before any runtime layer loads. The archived v0.2 masters remain in the repository until production review is complete.
