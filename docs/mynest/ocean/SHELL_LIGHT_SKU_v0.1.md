# Shell Light SKU v0.1

Working ID: `SKU_OCEAN_002_SHELL_LIGHT`  
Priority: P1  
Role: night light, interaction anchor, and short story event.

## Frozen prototype brief

- Small matte shell form with warm, soft diffusion and a stable low-brightness state.
- Four conceptual states: `OFF`, `DISCOVERY_GLOW`, `STORY_GLOW`, `SLEEP_GLOW`.
- No rapid colour changes, exposed hot surface, novelty-toy styling, or gaming-light behavior.
- IoT integration is not required for scene validation; the browser prototype simulates the state change at the mapped anchor.

## Scene function

Touching the Shell Light produces one 3–6 second glow, gathers nearby fish, and reveals one small creature before returning to idle. The shell dims when Milo returns home.

## Not yet frozen

Dimensions, electrical architecture, lumen range, thermal test, material certification, control interface, supplier, MOQ, and cost remain pending physical prototype review. No inventory order is authorized.
