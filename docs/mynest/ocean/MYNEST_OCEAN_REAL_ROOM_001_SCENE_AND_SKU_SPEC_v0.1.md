# 1. Core Correction

Ocean Room must not behave like:

```text
immersive exhibition
full-room projection spectacle
animated wallpaper
theme-park bedroom
```

It must behave like:

> **a real child's bedroom where a small number of ocean creatures appear to live.**

The real room remains visually dominant.

The magic is selective.

---

# 2. Frozen Product Formula

```text
REAL ROOM
+
LOW-ZONE DIGITAL LIFE
+
MILO
+
2–3 INTERACTIVE PHYSICAL OBJECTS
+
BEDTIME RETURN
=
MYNEST OCEAN ROOM
```

Do not expand beyond this for Room 001.

---

# 3. Room Design Principle

The room itself should remain:

```text
warm
quiet
credible
minimal
livable
premium
```

Preferred base:

```text
warm cream walls
pale oak furniture
simple child bed
small bookshelf
one bedside lamp
soft curtain
clean floor
limited decoration
```

Avoid:

```text
full ocean mural
heavy blue walls
too many themed objects
theme-park furniture
large cartoon stickers
excessive glowing products
```

The digital creatures should create the Ocean identity.

The furniture should not need to shout “ocean”.

---

# 6. Spatial Interaction Boundary

Digital life must remain inside defined activity zones.

The purpose is to make the creatures feel physically present rather than visually overwhelming.

---

# 7. Zone A — Floor Edge Zone

Location:

```text
floor near wall
bed edge
bookshelf base
room corners
```

Recommended visual height:

```text
0–30 cm from floor
```

Allowed digital elements:

```text
small fish
small shell glow
small creature
water-light reflections
```

Behavior:

```text
slow movement
pause
hide
return
```

Do not create continuous high-speed movement.

---

# 8. Zone B — Child Interaction Wall Zone

Recommended height:

```text
30–120 cm above floor
```

This is the primary child-interaction zone.

Allowed:

```text
small fish
Milo low pass
shell interaction
reef interaction
```

This zone should receive the highest interaction density.

Reason:

> children can naturally point, tap, follow, and crouch near it.

---

# 9. Zone C — Milo Transit Zone

Milo may temporarily exceed the normal low-zone limit.

Allowed movement:

```text
wall mid-height
bed-headboard height
window edge
short ceiling transition
```

Milo may use higher space only for:

```text
arrival
signature interaction
bedtime return
magic moment
```

Milo should not continuously circle the whole room.

---

# 10. Zone D — Sleep Zone

Centered around:

```text
bed
Milo Plush
Shell Light
```

During bedtime:

```text
digital activity collapses toward this zone
```

The room should visually become smaller and calmer.

---

# 11. Digital Movement Rule

Every digital creature must have:

```text
MOVE
STOP
OBSERVE
HIDE
RETURN
```

Not:

```text
LOOP FOREVER
```

This is essential.

Living things pause.

Screens loop.

MyNest should feel alive.

---

# 12. Small Fish Behavior

Fish are environmental life, not characters.

Use:

```text
3–7 fish visible maximum
```

Typical behavior:

```text
swim along wall edge
follow touch briefly
hide behind bookshelf
pause near shell
scatter gently when Milo arrives
```

Do not turn fish into a game mechanic.

---

# 13. Fish Interaction

Simple v0.1 interaction:

### Follow

Child touches / points / moves pointer.

```text
fish approach slowly
```

Then after a few seconds:

```text
fish resume independent behavior
```

Do not create permanent cursor-following behavior.

---

# 14. Shell Interaction

The shell can exist as:

```text
physical Shell Light
+
digital shell event
```

Interaction:

```text
child touches/clicks shell area
↓
shell emits soft glow
↓
small digital creature or fish appears
↓
short event
↓
returns to idle
```

Keep event:

```text
3–6 seconds
```

# 18. MILO_IDLE

Behavior:

```text

brief stop
look toward room / child
leave scene
```


# 25. Step 1 — World Quieting

Trigger:

```text
REST mode
BEDTIME
or scheduled wind-down
```

Actions:

```text
fish count decreases
fish movement slows
shell interaction stops
water-light intensity reduces
ambient sound softens
```

Duration:

```text
2–4 sec
```

---

# 26. Step 2 — Milo Notices Bedtime

Milo:

```text
slows
turns toward bed
briefly faces child
```

Optional small gesture:

```text
gentle tail movement
```

No long voice line.

---

# 27. Step 3 — Milo Swims Toward Plush

Path:

```text
current wall location
↓
bed edge
↓
Milo Plush location
```

This route must use room geometry.

Milo may:

```text
pass behind bed
partially disappear behind furniture
re-emerge near plush
```

This is critical for realism.

---

# 28. Step 4 — Digital-to-Physical Transfer

When Milo reaches physical plush:

```text
digital Milo slows
↓
soft glow appears around plush
↓
digital Milo reduces opacity / scale
↓
movement converges into plush position
↓
digital Milo disappears
```

Do not use flashy portal effects.

Target feel:

> Milo went home.

Not:

> Milo teleported.

---

# 29. Step 5 — Plush Sleep State

After transfer:

```text
plush remains physically present
soft local glow remains
room becomes quieter
```

Optional:

```text
one soft breathing light cycle
```

No continuous bright animation.

---

# 30. Step 6 — Final Ocean Sleep State

Only retain:

```text
very subtle water-light
minimal ambient sound
optional Shell Light low glow
physical Milo present
```

All active creatures disappear.

Final message if needed:

```text
Milo is sleeping.
```

or:

```text
Good night, Milo.
```

Use at most one.

---

# 31. Bedtime Principle

The child should understand:

> Milo has not gone away.

Milo now exists physically beside them.

This is the emotional purpose of the plush.
