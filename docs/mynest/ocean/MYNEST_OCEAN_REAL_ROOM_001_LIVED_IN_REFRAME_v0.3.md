# 69. Frozen Doctrine

> **Do not photograph the room like a designer. See it from the child's height.**

> **The room must look lived in before it looks magical.**

> **Milo belongs on the bed, not in a product display.**

> **Shell should look like a beautiful light before it looks like a shell.**

> **Reef should look like an object before it looks like coral.**

> **Do not tell the child something lives here. Let the child notice it.**

> **The first 100vh belongs to the room, not to MyNest.**

> **The fold is where explanation begins.**

> **MyNest is not selling an ocean-themed bedroom. It is assembling what the child needs for the first own-room night—and giving those few things a living world.**
