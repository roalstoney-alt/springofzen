# Ocean Room 001 — First Viewport v0.3

## Rule

The first 100vh contains only the room, a tiny sound control, and a tiny Rest control. There is no headline, prompt, CTA, room label, logo, product explanation, notebook, or experiment language.

## Timeline

- 0.0 s: real room only; digital organisms absent.
- 1.5 s: Sound and Rest controls fade in with low visual weight.
- 3.0 s: one baby fish appears near Reef.
- 4.5 s: the first fish pauses.
- 6.0 s: a second fish appears near the floor/wall junction.
- 8.0 s: a third small movement expands the sense of life.
- 10.5 s: digital Milo may begin entering after fish establish the room as inhabited.
- 13.5 s: autonomous resident timing begins.

Reduced-motion mode preserves the order through gentle fades and shortened waits.

## Interaction boundary

The existing finite fish behavior, Milo behavior, Shell response, Reef response, Rest sequence, and return-to-plush sequence remain. No new interaction, creature, world, product, event schema, or data collection is introduced.

## Replay and failure

Replay is available below the fold. If runtime animation fails, the room remains complete because the physical Milo, pearl light, and abstract stone object are part of the base art.
